# Personal Website — Dr.-Ing. Kun Gao

Personal academic homepage for **Dr.-Ing. Kun Gao**, researcher in automated driving safety, AI-based perception, and scenario-based validation at FKFS / University of Stuttgart.

**Live site:** [kun-gao.vercel.app](https://kun-gao.vercel.app)

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui components
- Lucide icons

## Sections

- **Hero** — name, title, affiliation, key links
- **About** — research background and focus
- **Experience** — FKFS, Daimler AG, Robert Bosch GmbH
- **Education** — Dr.-Ing. (Stuttgart), M.Sc. (KIT), B.Eng. (BIT)
- **Research** — three core research areas
- **Publications** — selected papers with Google Scholar links
- **Contact** — email, Google Scholar, LinkedIn, institute

## Local Development

```bash
npm install
npm run dev        # http://localhost:5173
```

## Build

```bash
npm run build      # output in dist/
```

## Deploy

Deployed on [Vercel](https://vercel.com). Push to `main` triggers automatic deployment.
